# 디자인 명세 템플릿

사용자가 대상의 디자인을 레퍼런스나 초안으로 쓰겠다고 요청할 때만 만든다. 기본 분석 리포트에는 포함하지 않는다. 목표는 이 문서만 읽고 같은 화면을 다시 그릴 수 있는 수준이다. 그 수준에 도달했는지는 문서가 아니라 아래 재현 검증으로 판정한다.

## 소유권 게이트

먼저 대상이 누구 것인지 확인한다. 확인할 수 없으면 제3자로 본다.

| 대상 | 모드 | 남기는 것 | 빼는 것 |
| --- | --- | --- | --- |
| 자사 또는 사용자 본인 산출물 | 실측 스냅샷 | 토큰 값, 픽셀 표, 컴포넌트 변형과 상태, 모션 상수, 카피 톤 | 없음 |
| 제3자 산출물 | 파생 규칙 | 위계 비율, 면 리듬, 그리드 구조, 상태 모델, 컴포넌트 구조, 모션 성격 | 색상 값, 서체명, 로고와 일러스트, 카피 원문, 실측 픽셀 표, 사이트맵을 옮긴 페이지 구성 |

제3자 판독 기록은 참고 자료이지 재현 허가가 아니다. 파생 규칙 모드에서는 값이 아니라 값을 만드는 규칙을 적고, 실제 값은 구현 스킬이 자기 브랜드 값으로 계산한다.

## 입력별 재현 한계

| 입력 | 재현 가능 | PARTIAL | UNKNOWN |
| --- | --- | --- | --- |
| CSS와 마크업 | 토큰, 타이포 위계, 레이아웃, 컴포넌트 변형, CSS transition | JS 모션 상수, 실행해야 보이는 hover·focus | 폰트 라이선스, 원본 이미지 자산 |
| 번들된 CSS | 토큰 값, 컴포넌트 구조 | 토큰 명칭과 계층 | 값의 근거 |
| 스크린샷 | 없음 | 위계와 리듬의 근사값 | 나머지 전부 |

스크린샷만으로는 이 문서를 만들지 않는다. 근사값 문서는 재현 문서가 아니다.

## 구조

### 1. 한 줄 아이덴티티

이 디자인이 무엇을 우선하는지 한 문장. 코드에는 이유가 없으므로 INFERRED이고, 어떤 관찰에서 추론했는지 근거를 나열한다.

### 2. 토큰

색, 타이포(패밀리, 크기, 굵기, 행간, 자간), 간격, radius, border, shadow, z-index, 브레이크포인트. 실측 스냅샷 모드에서는 CSS 변수와 실제 값을 위치와 함께 적는다. 파생 규칙 모드에서는 비율과 단계 수만 적는다.

```text
--color-surface-1: #ffffff        tokens.css:12
--space-4: 16px (기준 4px × 4)     tokens.css:31
```

### 3. 타이포 위계

단계마다 크기, 굵기, 행간, 쓰이는 자리. 단계 사이 비율을 함께 적는다.

### 4. 레이아웃

컨테이너 폭, 그리드 열, 거터, 면 분할 규칙, 브레이크포인트별 변화, 스크롤 영역 처리.

### 5. 컴포넌트 인벤토리

컴포넌트마다 변형 축(예: 계층 × 크기 × 유형)과 상태 축(기본, hover, focus, active, disabled, loading, error, selected)을 표로 적는다. 상태가 어떤 수단으로 표현되는지도 적는다. data 속성, class, aria 속성 중 무엇인가.

| 컴포넌트 | 변형 축 | 상태 축 | 상태 표현 수단 | Evidence |
| --- | --- | --- | --- | --- |

### 6. 모션

transition과 animation의 속성, 시간, 이징, 트리거. JS로 구동되는 모션은 상수 위치를 적고 PARTIAL로 둔다.

### 7. 자산

아이콘 세트, 일러스트, 이미지의 종류와 크기. 파일이 없으면 자리와 크기만 적는다.

### 8. 카피 톤

문장 종결 방식, 용어 표기, 상태 문구의 형식. 실측 스냅샷 모드에서만 원문을 인용한다.

### 9. 안티패턴 후보

이 디자인이 일관되게 피하는 것. 예를 들어 그림자 없음, 그라디언트 없음, 굵기 700 미사용. 세 화면 이상에서 확인될 때만 적고 관찰 횟수를 붙인다.

### 10. 재현 한계

문서로 넘길 수 없는 것을 명시한다. 폰트 라이선스, 원본 이미지, 미확인 hover 상태, 브레이크포인트 밖 동작, 근거를 알 수 없는 값.

## 재현 검증

문서만으로 화면 하나를 다시 그린 뒤 원본과 대조한다. 다음이 모두 맞을 때만 재현 가능이라고 쓴다.

- 토큰 값이 일치한다 (실측 스냅샷 모드) 또는 비율과 단계가 일치한다 (파생 규칙 모드)
- 타이포 위계의 단계 수와 비율이 일치한다
- 컴포넌트 상태가 모두 표현된다
- 레이아웃이 확인된 브레이크포인트 안에서 일치한다

하나라도 어긋나면 어느 절이 부족했는지 적고 문서를 고친다. 대조 없이 재현 가능이라고 쓰지 않는다.
