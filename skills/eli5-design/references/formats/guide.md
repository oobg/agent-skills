# guide — 따라하기 가이드

## 독자가 다 읽고 답할 수 있어야 할 질문

- 전부 하는 데 얼마나 걸리는가?
- 시작 전에 무엇을 준비해야 하는가?
- 지금 몇 단계까지 했고, 각 단계가 끝났는지 어떻게 아는가?
- 막히면 어떻게 하는가?

## 요청 신호

"따라하기", "설치 가이드", "설정 방법", "온보딩 안내", "체크리스트로".

## 권장 구성 예시 (예시일 뿐, 순서를 강제하지 않는다)

header(총 소요 시간을 리드에) → 준비물 행 → checklist(진행률 + 단계: 제목·결과 한 줄·소요 시간, 펼치면 입력 예시) → accordion(막혔을 때).

단계 제목은 사용자가 하는 동작으로 쓰고, 결과 한 줄은 "끝나면 보이는 것"으로 쓴다.

합성 예: "주문 내보내기 자동 전송 켜기: 약 10분".

## 프리셋 안티패턴

- 7단계 초과. guide 체크리스트만 원칙 단계 상한(5)의 예외로 7까지 허용한다. 실행 순서를 끊지 않기 위해서다. 넘으면 준비 단계를 별도 가이드로 나눈다.
- 완료 판정이 모호함("확인하기", "점검").
- 사용자가 할 일과 시스템이 하는 일이 한 목록에 섞임(시스템 일은 결과 한 줄로만).

## 경계

- 체크박스가 필요하면 guide, 이해만 하면 flow.
