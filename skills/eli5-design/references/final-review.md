# final-review — 최종 렌더 검토

완성한 결과를 넘기기 전에 한 번 거친다. 사람처럼 봐야 아는 것은 네 질문이, 기계가 확실히 아는 것은 검사 스크립트가 맡는다.

## 네 질문

실제 결과를 렌더한 뒤 전체를 한 번 훑고 다음 네 질문을 확인한다.

1. 글을 읽지 않고 그림·표만 훑어도 각 섹션이나 장의 핵심이 보이는가? 원과 선만 남은 그림이면 본문의 비유가 그림 속 사물로 들어갔는가?
2. 글·카드·캡션이 그림이나 표에서 이미 보인 내용을 다시 말하거나, 그림으로 올릴 순서·비교·구성·경로·항목 뜻을 문단으로 들고 있지 않은가?
3. 겹치거나 잘리거나 넘친 곳이 없고, 그림 속 역할·대상이 원문에 나온 실제 이름으로 식별되는가?
4. 각 주장·결정의 근거가 화면에 실제로 보이는가? 필요한 값·상태·없음이 빠지지 않았고, 제목은 그 근거보다 강하게 말하지 않는가?

하나라도 아니면 해당 부분을 고친 뒤 다시 렌더한다.

## 렌더하는 법

- page는 넓은 화면(약 1440px)과 좁은 화면(약 390px)에서 위에서 아래까지 본다. deck은 한 장씩 넘기며 모든 장을 본다.
- 스크린숏을 찍어 직접 본다. 라벨이 선·점 위에 얹혔는지, 좁은 화면에서 라벨이 몰렸는지는 숫자 검사로 다 잡히지 않는다. page면 기계 검사가 만든 본보기 비교 이미지(출력 마지막 줄)를 연다.
- deck은 사용자가 정한 장 수에서 크게 벗어나지 않았는지, 근거 없이 글자만 있는 장이 남았는지도 이때 본다.

## 기계 검사

```bash
node scripts/check_render.cjs out.html            # 기본 1440·390px
node scripts/check_render.cjs out.html --widths 1440,390,320 --playwright <playwright-core 경로>
```

| 검사 | 실패 기준 |
| --- | --- |
| 콘솔·스크립트 오류 | 하나라도 있음 |
| 페이지 가로 넘침 | 문서 `scrollWidth`가 실제 레이아웃 폭(`clientWidth`, 스크롤바 제외)보다 1px 넘게 큼. 표·그림 안 가로 스크롤 상자는 넘침이 아니다 |
| SVG 잘림 | 정보 SVG의 도형·글자 합집합이 SVG 상자 밖으로 1px 넘게 나감 |
| 내부 식별자 노출 | 보이는 글에 스크립트 목록의 slug가 정확히 일치함(코드·접기·인용 안은 제외) |
| 남은 자리표시자·토큰 | `/* eli5:… */`가 남았거나 토큰이 인라인되지 않음 |
| 외부 요청 | 폰트 폴백 링크 밖의 외부 요청 |
| 넓은 구간 속 작은 그림 | `.d0-wide` 안 글자 있는 SVG의 viewBox 폭이 바로 안 750, 2열 칸 480보다 작음 |
| 그림 글자 크기 불일치 | 폭마다 그림별 글자 렌더 크기 중앙값과 축 기준 그림의 최대/최소 비가 1.35 초과(작게·그림 안 스크롤 제외) |
| report 표지 회귀 | `data-width="report"` page에서 머리·본문 블록 폭이 기본 축과 다르거나, 중심선·시작선이 1px 넘게 어긋나거나, `.d0-wide`가 넓은 구간 폭이 아님. report 덱의 bottom·contrast·center 표지가 1열이 아님 |

- 그림 글자 절대 크기는 경고로만 나온다. SVG의 실제 렌더 폭으로 재므로 스크롤바 유무로 판정이 바뀌지 않는다.
- 스크립트가 FAIL을 내면 고치고 다시 돌린다. WARN은 렌더를 보고 판단한다.

## 렌더할 수 없을 때

이 검토를 통과한 것으로 기록하지 않는다. [render-unavailable.md](render-unavailable.md)를 열어 안전 모드로 만들고, 소스만으로 답할 수 있는 질문(2·4)만 확인한 뒤 시각 항목은 `확인 불가`로 보고한다. 자동 게시하지 않는다.

## 넘기기

- 넘기기 직전 `scripts/subset_font.py`로 폰트 서브셋을 인라인해 외부 요청을 0건으로 만든다. 도구가 없으면 폰트 링크 하나를 남기고 사용자에게 알린다.
- 게시가 필요하거나 호스트가 게시를 기본으로 요구하면 [publishing.md](publishing.md)를 연다. 로컬 HTML 파일은 늘 남긴다.
