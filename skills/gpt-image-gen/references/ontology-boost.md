# 온톨로지 보강 (선택)

`~/.ontology/ontology.db`가 있을 때만 편다. **없으면 이 파일을 무시하고 본문대로
프롬프트를 그대로 넘긴다** — 이 모듈은 프롬프트를 짜는 방법을 보태는 보조 계층이지
생성 경로의 일부가 아니다.

**비용 게이트는 이 모듈이 열려 있어도 그대로다.** 회수해서 좋은 프롬프트가 나왔다는 것이
생성 허가가 되지 않는다. 사용자가 `/gpt-image-gen`을 직접 입력한 경우에만 생성한다.

## 언제 여는가

| 상황 | 회수해서 얻는 것 |
| --- | --- |
| 프롬프트가 한 줄이고 결과 편차가 클 것 같을 때 | 층을 나눠 쓰는 순서 |
| 제품·브랜드 자산이 걸린 이미지 | 그 프로젝트의 팔레트·폰트·표기 |
| 재생성 요청 — 뭘 고쳐야 할지 갈릴 때 | 어느 층을 건드릴지 |

프롬프트가 이미 구체적이고 사용자가 원하는 그림이 분명하면 열지 않는다. 회수는 공짜가
아니고, 이 스킬의 병목은 프롬프트 품질이 아니라 사용량이다.

## 프롬프트를 층으로 나눈다

한 덩어리로 쓴 프롬프트는 결과가 어긋났을 때 어디를 고쳐야 할지 알 수 없다. 층을 나누면
수정할 층이 식별된다.

```
이미지 구상 → 주제(도메인 + 구체적 화면·오브젝트 유형) → 핵심 요소
  → 스타일·분위기 → 생성 파라미터 → 최종 조합
```

- **주제는 도메인과 구체적 유형을 함께** 적는다. "대시보드"가 아니라 "프랜차이즈 본사
  매출 모니터링 대시보드"다.
- **핵심 요소를 구체적으로 넣으면** 결과가 의도한 실제 구조에 가까워진다.
- 계층 명세가 필요한 작업(브랜드 키트·로고·제품 컨셉)에서는 역할 부여, 브랜드 DNA,
  모듈형 레이아웃, 재질·카메라 제약, **금지 조건**까지 층으로 적는다.

## 다른 모델에서 관측된 것 (그대로 적용하지 않는다)

KB의 레이아웃·일관성 관측치는 **Nano Banana Pro를 쓴 제3자 저자의 실험**에서 나온 것이고,
일부는 원문에서 `저자 관찰`로 헤지돼 있다. 이 스킬이 호출하는 경로(Codex `@imagegen`)와
모델이 다르므로 검증된 한계로 옮겨 적지 않는다. 참고 가설로만 쓰고, 실제로 깨지는지는
이 경로에서 확인한 뒤 판단한다.

- 그 저자는 복잡 비대칭 그리드와 슬로건 분배가 자주 깨졌고 다층 레이아웃에는 사람이
  필요하다고 관찰했다. 한 장에 다층 레이아웃을 욕심내기 전에 이 가설을 떠올릴 만하다.
- 같은 실험에서 멀티 이미지 입력은 레퍼런스가 늘수록 캐릭터 일관성이 떨어졌다. 다만
  `scripts/generate.sh`에는 레퍼런스 이미지 입력 경로 자체가 없으므로 지금 이 스킬에는
  적용할 자리가 없다.
- 층을 늘리는 것과 문장을 늘리는 것은 다르다. 층은 나누되 각 층은 짧게 쓴다.

## 브랜드 자산 회수

제품·브랜드가 걸린 이미지면 팔레트·폰트·고정 표기를 KB에서 회수해 스타일 층에 넣는다.

1. **스코프를 먼저 고정한다.** 회사 제품 → `company` + `shared` · 개인 →
   `personal` + `shared` · 방법론·도구 문서용 그림 → `shared` · 작품 이미지 →
   `novel` + `shared`.
2. **`~/.ontology/docs/recall.md`를 읽고 그대로 따른다.** 단계별 SQL과 근거 표기 형식이
   거기 있다. 여기 복제하면 갈라진다. **`recall.md`가 없으면 SQL을 지어내지 말고 이 모듈을
   닫는다** — 온톨로지가 없는 것과 같이 취급하고 사용자 프롬프트를 그대로 넘긴다.
3. 회수 0건이면 브랜드 값을 지어내지 말고 사용자에게 묻거나 브랜드 지정 없이 생성한다.

## 회수 결과를 그대로 믿지 않는다

**회수는 무엇을 봐야 하는가를 알려주는 것이고, 지금 어떤 상태인가의 증거가 아니다.**
팔레트·로고·폰트는 바뀐다. 회수한 값을 프롬프트에 넣기 전에 지금도 유효한지 확인하거나,
확인하지 못했으면 어느 시점의 값인지 사용자에게 밝히고 넘긴다.

## 바뀌지 않는 것

- 명시 호출 전용 게이트, 빈 프롬프트 되묻기, 배경 제거 기본값
- 출력 규약(`./generated-images/`, `SAVED <절대경로>` 보고)
- 병렬 호출 시 사용량이 호출 수만큼 늘어난다는 사실. 대량 생성 전 규모 확인
- 스코프 밖 tenant의 자산은 프롬프트에도 보고에도 넣지 않는다
