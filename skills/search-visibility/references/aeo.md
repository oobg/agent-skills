# AEO — 답변엔진에 추출되기

검색 결과 상단의 AI 답변 박스가 인용하게 만드는 레인이다.

**이 문서의 요건은 공식 문서로 확정된 것이 아니라 관측에서 추린 가설이다.** 답변엔진이
페이지를 요약하기보다 답이 되는 문장을 추출한다는 전제, 아래의 길이·형태 기준, 한 페이지에
여러 질문을 담으면 불리하다는 서술 모두 검증 대상이다. 대상 질문의 인용 여부를 실제로
확인해 검증하고, 검증 전에는 처방이 아니라 시험 대상으로 다룬다. 다른 레인의 근거 등급은
[geo.md](geo.md) 1절과 [neo-naver.md](neo-naver.md) 2절에 있다.

## 원칙: 질문 하나에 페이지 하나

- 사람들이 검색창에 치는 질문마다 전용 페이지를 둔다. 한 페이지에서 여러 질문을
  다루면 어느 질문에 대해서도 답이 흐려진다(가설이며, 페이지를 쪼갠 전후로 인용을 재봐야
  확인된다).
- URL, h1, title이 질문을 그대로 반영한다.
- 질문 목록은 검색 콘솔의 검색어, 검색 결과의 연관 질문 블록, 경쟁 페이지의 FAQ,
  고객 문의, 사용자 인터뷰처럼 출처가 있는 데서 만든다. 지어낸 질문으로 페이지를 늘리면
  색인 예산만 쓴다. 질문 선정 절차는 [citation-competition.md](citation-competition.md)에 있다.

## 추출되는 문장의 형태

- [ ] **첫 문단이 직답이다.** 질문에 대한 답을 한 문장으로 페이지 최상단에 둔다. 40자 내외를
      권장하되 이 숫자는 외부 출처가 아니라 이 문서의 기준이며, `crawl_audit.py`도 이 값으로
      판정하지 않고 관측치만 보여 준다.
- [ ] **문장이 독립적으로 사실을 말한다.** "위에서 말한 그 수치"처럼 맥락에 기대는 문장은
      추출되는 순간 무의미해진다. 각 문단이 주어, 수치, 기준일을 자체 보유한다.
- [ ] **기준과 날짜를 밝힌다.** "13.8배(2026-08-26, 최근 4개 분기 기준)"처럼 쓴다.
      기준 없는 숫자는 신뢰 판정에서 감점된다.
- [ ] **표를 쓴다.** 표는 항목과 값이 붙어 있어 문단보다 잘라 쓰기 쉽다(가설).
- [ ] **소제목을 고객이 서 있는 상황으로 쓴다.** 키워드를 반복한 소제목보다, 하위 질문과
      맞물리는 소제목이 문단 단위로 잘려 인용된다.
- [ ] **하위 질문을 센다.** 질문 하나는 여러 하위 질문으로 갈려 각각 검색된다.
      우리 페이지가 그중 몇 개에 답하는지 확인한다.

## FAQ 블록

- [ ] 페이지 하단에 실제 검색 질문 3~5개로 FAQ 섹션을 만든다.
- [ ] FAQPage JSON-LD를 붙이되 가시 텍스트와 글자까지 같게 한다. 다르면 스팸으로 판정된다.
- [ ] 데이터로 확정되는 것만 답으로 쓴다. 예측이나 권유형 문답은 넣지 않는다.
      금융, 의료, 법률처럼 규제 업종이면 특히 그렇다.

## 검증

- 배포 후 대상 질문을 실제로 검색해 AI 답변의 인용 여부를 확인하고 O/X로 기록한다.
- 인용되지 않으면 순서대로 점검한다. ① 직답 문장이 첫 화면에 있는가
  ② 경쟁 페이지 대비 데이터가 최신인가 ③ 도메인과 구조화 데이터의 신뢰 신호가 있는가.
- 인용은 변동한다. 한 번 확인한 결과를 상태로 굳히지 말고 재측정 일정에 넣는다.
