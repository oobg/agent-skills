# Engineering Shorts

건축, 도시, 기계, 항공, 밀리터리 엔지니어링과 유체역학을 주제로 시네마틱 세로형
공학 설명 쇼츠를 제작하는 스킬입니다.

대본, 인포그래픽 없는 CLEAN 키프레임, 같은 구도의 INFO 편집본, CLEAN에서 INFO로
그래픽이 조립되는 4초 영상, 최종 편집의 순서로 작업합니다. 각 단계 사이에는 승인
게이트가 있고 실제 화면으로 자산을 검수합니다.

## 구성

- [`SKILL.md`](SKILL.md): 트리거, 단계 판정, 승인 게이트, 공통 실행 계약
- [`workflow.md`](references/workflow.md): 조사와 대본부터 게시까지 단계별로 만들고 검수하는 규칙
- [`prompt-templates.md`](references/prompt-templates.md): 새 프로젝트, CLEAN, INFO, 영상 프롬프트 템플릿

설치 방법은 저장소의 [루트 README](../../README.md)를 참고하세요.
