# Engineering Shorts

건축, 도시, 기계, 항공, 밀리터리 엔지니어링과 유체역학을 주제로 시네마틱 세로형
공학 설명 쇼츠를 제작하는 스킬입니다.

대본, 인포그래픽 없는 CLEAN 키프레임, 같은 구도의 INFO 편집본, CLEAN에서 INFO로
그래픽이 조립되는 4초 영상, 최종 편집의 순서로 작업합니다. 각 단계 사이에는 승인
게이트가 있고 실제 화면으로 자산을 검수합니다.

## 사용 시점

- 공학 원리를 세로형 쇼츠로 설명할 때
- CLEAN 이미지와 INFO 편집본을 같은 구도로 제작할 때
- 이미지에서 정보 그래픽으로 조립되는 4초 영상을 설계할 때

일반 영상 편집이나 공학 사실 조회만 필요한 작업에는 적용하지 않습니다.

## 핵심 동작

조사와 대본, CLEAN 이미지, INFO 편집, 4초 영상, 최종 편집 순서로 진행합니다.
각 단계의 산출물을 실제 화면으로 확인하고, 다음 단계로 넘어가기 전에 필요한 승인을
받습니다.

## 사용 예

```text
와류가 날개 끝에서 생기는 이유를 45초 공학 쇼츠로 만들어줘.
```
