# 어체 (문장 끝맺음)

문장 끝맺음을 어디서 어떤 걸 쓸지 표로 정해둔다. 기본은 `~해요`체이고, 도메인
때문에 못 쓰면 바꾼다. 검사는 `scripts/register_check.py`가 한다. **대상 파일의
경로가 아래 프로젝트 경로 밑이면 그 프로젝트 어체를, 아니면 전역 기본을 따른다.**

> **경로 해석 주의:** 프로젝트 어체는 대상 파일의 경로로 정한다. 출력 파일을
> 임시 폴더(예: `/mnt/.../outputs`)에 새로 만드는 샌드박스/파일 생성 환경에선 그
> 경로가 실제 프로젝트 경로(`/Users/...`)와 안 맞아 프로젝트 어체가 조용히 안
> 걸린다. 이럴 땐 `register_check.py ... --as <실제경로>`로 실제 적용처를 넘긴다.

쓸 수 있는 어체: `해요체`, `합니다체`, `한다체`, `음슴체`.

## 온보딩 상태

`references/setup.md` 온보딩을 한 번 거쳤는지 기록한다. **어체/글로서리를 비워
두기로 했어도(=그냥 기본으로) 이 값은 `완료`로 남긴다.** 이게 `완료`면 표가 비어
있어도 다음 세션에 온보딩을 다시 띄우지 않는다.

| 항목 | 값 |
| ---- | -- |
| 온보딩 | (안 함) |

`(안 함)`이면 어체 미지정 + 글로서리 비어 있을 때 온보딩이 한 번 뜬다. 거치고
나면 `완료`로 바꾼다. (스킬 폴더가 읽기 전용이라 이 값을 못 고치는 환경이면
setup.md의 `스킬 파일을 못 고치는 환경이면` 절을 따른다.)

## 전역 기본

| 범위 | 어체 |
| ---- | ---- |
| 전역 기본 | (미지정) |

`(미지정)`이면 어느 프로젝트에도 안 걸리는 글은 어체를 강제하지 않는다(README
같은 평서체 문서 보호). 위 어체 중 하나를 적으면 전역으로 강제한다.

## 프로젝트 단위

특정 프로젝트만 다른 어체를 쓰면 경로와 함께 적는다. 대상 파일이 그 경로 밑에
있으면 이 어체가 전역보다 우선한다. 경로가 겹치면 더 깊은(긴) 경로가 이긴다.

| 프로젝트 | 경로 | 어체 |
| -------- | ---- | ---- |
| _(예) 사내 어드민_ | _/Users/me/work/admin_ | _합니다체_ |

예시 행은 지우고 실제 프로젝트를 적는다. 비어 있으면 전역 기본만 적용된다.
`~`(홈 디렉터리)와 절대 경로 둘 다 된다.

## 어체 설정 대화

어체는 **임의로 바꾸지 않는다.** 사용자에게 물어서 정하고, 정해진 결과를 위
표에 적는다. 질문은 선택지(버튼)로 낸다.

### 처음 — 어체가 미지정일 때

처음 설정은 `references/setup.md` 온보딩에서 어체와 도메인 단어를 한 번에 묻는다.
여기서는 그 이후의 "어체 변경" 요청 흐름만 다룬다.

### "어체 변경해줘" 요청이 오면 — 2뎁스

**1단계, 범위를 묻는다.**

> 어디에 적용할까요?
> - 기본값(전역)을 바꾼다
> - 현재 프로젝트에만 적용한다

**2단계, 어체를 고르게 한다.**

> 어떤 어체로 할까요?
> - ~해요 (추천)
> - ~합니다
> - ~한다
> - ~음 / ~함 (개조식)
> - 내 어체를 분석해서 반영하고 싶어요

### 고른 결과를 표에 적는다

- 전역을 골랐으면 `전역 기본` 표의 어체를 바꾼다.
- 프로젝트를 골랐으면 `프로젝트 단위` 표에 `이름 | 현재 작업 경로 | 어체` 한 줄을
  추가한다. 경로는 지금 작업 중인 프로젝트의 루트를 적는다.

### "내 어체를 분석해서 반영하고 싶어요" (placeholder)

이 항목을 고르면, 사용자가 자기 문장을 바로 붙여넣게 한다.

> 평소 쓰는 문장을 두세 개 붙여넣어 주세요. 그 끝맺음을 보고 맞출게요.

붙여넣은 글의 문장 끝맺음을 분석해 어느 어체인지(해요, 합니다, 한다, 음슴) 판별해
표에 적는다. 넷 중 하나로 깔끔히 안 떨어지면 가장 가까운 걸 제안하고 확인을
받는다. **없는 어체를 지어내지 않는다.**

## 가능하면 — 톤 보정 (선택)

스크립트로 강제하지 않고, 되도록 지키는 선호를 적는다. 여기 적은 건 사람이
판단해서 적용한다.

- (예) 피동보다 능동을 쓴다
- (예) 한 문장에 한 메시지
- (예) 감탄사는 자제한다
