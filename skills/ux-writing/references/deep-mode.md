# 딥모드 — 정서 보강 (더하기 축)

## 이건 뭐가 다른가

`ai-tells.md`, `translation-ese.md`는 전부 **빼기**다 — 티 나는 구절을 걷어
낸다. 딥모드는 반대다. **매끄럽고 문법도 맞는데 밋밋할 때**, 한국어 특유의
정서와 말맛을 일부러 더한다. 방향이 반대라 기본 흐름에 섞지 않고 여기 따로
둔다.

## 언제 여나

**기본값은 항상 꺼져 있다.** 아래 중 하나에 해당할 때만 연다.

- `/ux-writing:deep` 슬래시커맨드: 가장 명확한 트리거. 이게 오면 다른 조건
  따질 것 없이 바로 연다.
- 사용자가 자연어로 명시적 요청: "딥모드로", "정서까지 살려줘", "결까지
  다듬어줘", "더 깊게 봐줘" 등
- `ai-tells.md`의 게슈탈트 점검(1번과 2번, 리듬과 대칭)까지 다 했는데도 사용자가
  "그래도 뭔가 기계적이다"라고 재차 지적할 때

사용자가 그냥 "다듬어줘", "AI 티 빼줘"라고만 하면 **열지 않는다.** 기본
흐름(SKILL.md 표 → 필요시 ai-tells.md/translation-ese.md)으로 충분하다.

## 가드 3원칙 (먼저 확인)

1. **장르 가드** — 격식 보고서, 공문, 계약서, 공적 발표문에는 적용하지 않거나
   아주 약하게만. 칼럼, 에세이, 블로그, 후기, 브랜드 카피에 주로 쓴다.
2. **우선순위 가드** — `ai-tells.md`/`translation-ese.md`와 충돌하면 그쪽이
   이긴다. 정서를 살린다고 대명사를 다시 늘리거나 과장을 되살리지 않는다.
3. **비중 가드** — 이걸 핑계로 다른 글로 바꾸지 않는다. 원문의 사실, 주장, 수치는
   그대로 두고, 말맛만 만진다.

## 패턴

### K-1. 정서 온도 0 (추상과 일반론만 있음)

추상적 단언 하나마다 구체적 장면이나 수치를 하나씩 붙인다. 일반론 1개당
구체 사례 2개 정도 비율을 목표로 한다. (지어내지 않는다 — `ai-tells.md`
게슈탈트 점검 4번과 같은 원칙: 실제 경험이 없으면 비워두거나 묻는다.)

```
❌ 고객 경험이 중요하다.
✅ 한 번 불편을 겪은 손님은 돌아오지 않는다.
```

### K-2. 과장

강조어를 사실 서술 + 여백으로 바꾸거나, 이중부정이나 완서법(곡언)으로
무게를 낮춰 전달한다.

```
❌ 압도적인 성과를 거두었다.
✅ 기대를 적잖이 넘겼다.
```

### K-3. 빳빳한 완결형 (에세이, SNS, 후기)

문장 끝을 다 딱 부러지게 맺으면 오히려 사람 냄새가 없다. 일부 문장은
말끝을 흐리거나 여백을 남긴다. **격식 문서에는 적용하지 않는다.**

```
❌ 그게 문제입니다.
✅ 그게 제일 걸리더라고요.
```

### K-4. 공식적인 서두와 결말

"~에 대해 알아보겠습니다"로 열고 "~할 때입니다"로 닫는 정형화된 틀을
깬다. 서두는 장면, 질문, 반전으로, 결말은 여운이나 구체적인 한 문장으로.

```
❌ (서두) 오늘은 협업 문화에 대해 알아보겠습니다.
✅ (서두) 회의가 끝나고도 아무도 안 나가는 팀이 있다.

❌ (결말) 결국 소통이 중요한 때입니다.
✅ (결말) 결국 자리가 아니라 신뢰의 문제였다.
```

## 화계(말투 거리) 일관성

격식(합니다) / 정중(해요) / 친근(해체) 중 독자와 장르에 맞는 한 단계를
고르면, 글 전체에서 그 단계를 끝까지 유지한다. 정서는 문장 하나하나의
기교보다 이 거리를 얼마나 일관되게 지키느냐에서 더 크게 좌우된다.

# 참고표 — 영어 비즈니스 buzzword 번역

영어 원어를 그대로 음차해서 어색해지는 단어들. 이미 한국어로 옮겼는데 뜻이
어긋난 경우는 `translation-ese.md`의 `어휘 단위 직역`이 본다. 프로젝트 `glossary.md`에 이미
등록된 용어가 있으면 그쪽이 우선한다 — 이 표는 아직 온보딩 안 된 일반
buzzword에 대한 기본값이다.

| 영어 | 자연스러운 한국어 |
|---|---|
| leverage | 활용하다 / 기대다 / 끌어올리다 |
| seamless | 매끄러운 / 끊김 없는 |
| robust | 튼튼한 / 견고한 |
| scalable | 확장성 있는 |
| insight | 통찰 / 시사점 |
| impact | 영향 / 파장 |
| holistic | 전체적 / 총체적 |
| framework | 체계 / 틀 / 구조 |
| pipeline | 파이프라인(유지 가능) / 흐름 / 공정 |

일반 독자 대상 글이면 영어 원어는 처음 한 번만 괄호 병기하고 이후엔
한국어만 쓴다. 전문 독자 대상이면 영어를 유지해도 되지만, 매번 반복
병기하지는 않는다.
