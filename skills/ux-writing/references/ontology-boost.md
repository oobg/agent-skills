# 온톨로지 보강 (선택)

`~/.ontology/ontology.db`가 있을 때만 편다. **없으면 이 파일을 무시하고 본문대로
진행한다** — 이 모듈은 정확도를 올리는 보조 계층이지 필수 경로가 아니다.
글로서리가 차 있고 대상 파일 경로가 프로젝트 안에 있으면 본문만으로 충분하다.

## 언제 여는가

셋 중 하나라도 해당할 때만 연다. 그 외에는 열지 않는다 — 쓰이지 않을 조회가 쌓이면
무엇이 실제로 필요했는지가 통계에서 지워진다.

| 상황 | 온톨로지가 메우는 것 |
| --- | --- |
| `references/glossary.md`가 비었는데 도메인 표기가 갈릴 만한 글 | 실제로 쓰이는 표기의 후보 |
| 아티팩트·임시 경로라 프로젝트 규칙 탐색이 무력화됨 | 경로 대신 tenant 스코프로 규칙 회수 |
| 배치·고위험 문구라 판단형 근거가 필요함 | 같은 문구·판정을 과거에 어떻게 정했는지 |

두 번째가 이 모듈의 존재 이유다. `glossary_check`와 `register_check`는 대상 파일
경로로 프로젝트를 찾는데, 아티팩트는 언제나 임시 경로에 쓰이므로 `--as`로도 규칙이
안 걸린다. 온톨로지는 경로가 아니라 tenant로 스코프를 잡으므로 이 구멍을 지난다.

## 절차

1. **스코프를 먼저 고정한다.** 회사 제품 문구 → `company` + `shared` · 개인 →
   `personal` + `shared` · 스킬·방법론 문서 → `shared` · 소설 원고 → `novel` + `shared`.
2. **`~/.ontology/docs/recall.md`를 읽고 그대로 따른다.** 단계별 SQL, 스코프 누수 금지,
   근거 표기 형식이 거기 있다. 여기 복제하지 않는 이유는 한 규칙이 두 곳에 각자 적히면
   갈라지기 때문이다. **`recall.md`가 없으면 SQL을 지어내지 말고 이 모듈을 닫는다** —
   온톨로지가 없는 것과 같이 취급하고 본문 기본값으로 진행한다.
3. 표기 후보는 `concepts`에서 실제 이름을 확인한 뒤 `v_claim_concept`으로 내려간다.
   추측한 이름으로 조인하면 한 글자 차이로 회수가 0건이 된다.
4. 회수 0건이면 `KB에 없음`이라고 쓰고 본문 기본값으로 진행한다. 조회 실패를
   "축적된 지식 없음"으로 바꿔 말하지 않는다.

## 우선순위

```
프로젝트 파일(glossary.md · register.md) → 온톨로지 회수 → 본문 일반 원칙
```

온톨로지에서 나온 표기는 **후보이지 확정이 아니다.** 프로젝트 파일에 다른 표기가 있으면
파일이 이긴다. 회수한 표기를 글로서리에 적어 넣는 것은 사용자 동의가 있을 때만 한다.

## 회수 결과를 그대로 믿지 않는다

**회수는 무엇을 봐야 하는가를 알려주는 것이고, 지금 어떤 상태인가의 증거가 아니다.**
claim에는 시제가 없고, 문서 날짜는 그 시점에 관측됐다만 말할 뿐 이후 조치되지 않았다를
말하지 않는다. 표기·문구·라벨은 가변 산출물이므로 회수한 표기를 근거로 고치기 전에
지금 그 표기가 살아 있는지 확인한다. `grep` 한 번이면 되고, 틀린 수정의 비용보다 훨씬 싸다.

## 바뀌지 않는 것

- **HARD 0** 통과 기준은 그대로다. 온톨로지는 판단형 근거만 보태고 `ai_lint`를 대체하지 않는다.
  결정론적으로 판정 가능한 항목을 회수 판단에 맡기면 비용과 오탐이 함께 는다.
- `고치지 않는 것`(수치·고유명사·인용·법적 문구)은 온톨로지에 뭐가 있든 그대로 둔다.
- 과윤문·장르 이탈 게이트, 멈춤 규칙, 출력 계약도 그대로다.
- 스코프 밖 tenant의 문서·claim·건수는 답에 노출하지 않는다. 공유 concept 노드는
  스코프 밖을 열람할 권한이 아니다.

## 근거 표기

온톨로지를 근거로 문구를 고쳤으면 한 줄 남긴다. 형식의 정본은 `recall.md`다.

```
근거: company · 점주앱 · 「외식UP 앱 디자인 티어다운 (2026-07)」
근거: KB에 없음 (company+shared, concept·FTS 모두 0건) — 아래는 본문 기본값이다
```
