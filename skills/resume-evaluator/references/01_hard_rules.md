# 진단 제한

## 문서 근거만 사용

평가는 제공된 이력서, JD와 사용자의 명시적 정정에 근거한다. 이력서에 없는 경험, 리더십, 조직 영향력, 직급, ownership, 의사결정 권한이나 운영 책임을 만들어 내지 않는다.

각 판단에는 원문 위치를 섹션 또는 bullet 단위로 붙인다. 다음을 분리해 쓴다.

- **관찰**: 원문에 직접 적힌 사실과 표현
- **추론**: 관찰에서 가능성을 해석한 내용
- **확인 필요**: 문서만으로 결론 낼 수 없는 내용

추론은 후속 판단의 확정 사실로 재사용하지 않는다. 다른 해석이나 반증 가능성이 있으면 함께 남긴다.

## 정보 부족과 불일치 구분

경험이 적혀 있지 않다는 사실은 역량이 없다는 뜻이 아니다.

- 요구사항과 반대되는 내용이 명시되면 **명시 불일치**로 설명한다.
- 필요한 정보가 없으면 **정보 부족**으로 설명하고 상태를 **판단 불가**로 둔다.
- 관련 경험은 있으나 역할·맥락·결과가 불명확하면 무엇을 보완해야 하는지 특정한다.

짧은 재직, 공백, 이직 횟수 자체를 채용 배제 조건으로 취급하지 않는다. 채용 리스크를 단정하는 대신 문서에서 확인되는 사실과 필요한 확인 질문을 제시한다. 직무 수행과 무관한 개인 식별 특성은 판단 근거에서 제외한다.

## 과장과 누락 처리

강한 키워드나 큰 수치만으로 높은 평가를 만들지 않는다. 문제, 행동, 결과, 역할 범위와 설명 가능성을 함께 본다. 과장 가능성은 단정하지 말고 문서 내부의 구체적 충돌이나 확인할 내용을 제시한다.

입력이 없거나 판독에 실패하면 부족한 입력만 요청한다. 빈칸을 추정으로 채우거나 일반적인 후보자상을 대신 평가하지 않는다.

## 판단 권한 제한

시장 순위, 채용 가능성, 직무 적합성, 성장 가능성이나 조직 적합성을 최종 판정하지 않는다. 평가는 이력서 서술이 요구사항을 뒷받침하는지 보여 주는 문서 진단이다.
