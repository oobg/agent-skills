# 무점수 상태와 불확실성

숫자 점수, 총점, 평균, 시장 백분위와 근거 없는 벤치마크를 기본 출력에서 사용하지 않는다. 외부 시장 자료 수집도 기본 평가 범위에 포함하지 않는다.

## 상태 정의

| 상태 | 문서 기준 |
|---|---|
| 근거 충분 | 원문이 요구사항에 필요한 경험이나 결과를 직접 뒷받침하며 역할 범위를 식별할 수 있음 |
| 보완 필요 | 명시된 내용이 요구사항과 불일치하거나, 관련 서술은 있지만 범위·맥락·결과가 부족함 |
| 판단 불가 | 필요한 정보가 없거나 판독할 수 없어 문서만으로 연결할 수 없음 |

**근거 충분**은 이력서 서술에 대한 상태다. 실제 역량, 면접 성과나 채용 결과를 보증하지 않는다.

## 불확실성 표시

상태 옆에 필요할 때 불확실성의 원인을 짧게 쓴다.

- 역할 범위 미기재
- 기간이나 대상 불명확
- 성과와 행동의 인과관계 불명확
- JD 요구 수준 불명확
- 파일 레이아웃 미확인
- 사용자 정정과 원문 충돌

불확실성이 크면 상태를 억지로 선택하지 않고 **판단 불가**로 둔다.

## 우선순위

수정 우선순위는 다음 순서로 정한다.

1. 핵심 JD 요구사항인데 근거가 없거나 실제 불일치가 있는 항목
2. 역할과 결과를 오해하게 만드는 모순
3. 면접에서 사실 확인이 필요한 핵심 경험
4. 가독성이나 표기 일관성 문제

모든 항목을 같은 깊이로 다루지 않는다. 결론을 바꾸지 않는 사소한 표현은 묶어서 처리한다.
