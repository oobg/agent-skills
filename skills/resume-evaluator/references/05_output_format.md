# 05. 출력 구조 — 7개 섹션 포맷

평가 결과는 아래 7개 섹션 순서로 출력한다. 섹션 순서를 변경하지 않는다.

---

## 섹션 1. 전체 요약

다음 항목을 포함한다:

- 현재 이력서의 **전반적 인상**
- 어떤 유형의 후보로 읽히는지
- **가장 강한 요소**
- **가장 약한 요소**
- 시장 기준 위치 (평균 이하 / 평균 / 평균 이상 / 상위권 / 매우 강한 후보)
- confidence 수준 (높음 / 중간 / 낮음 + 이유)

---

## 섹션 2. 다차원 평가표

아래 표 형식으로 출력한다:

| 항목 | 점수 | 해석 |
|---|---|---|
| 신뢰도 | /10 | 경험 설명의 구체성과 검증 가능성 |
| 가독성 | /10 | 구조, 흐름, 정보 전달 명확성 |
| 차별화 | /10 | 동일 연차 대비 차별화 요소 |
| ATS 적합성 | /10 | 키워드, 구조, 파싱 안정성 |
| 인터뷰 유도력 | /10 | 면접관이 질문하고 싶어지는 요소 |
| 직무 적합성 | /10 | JD 또는 직무 기준 매칭도 |
| 성장 가능성 | /10 | 커리어 궤적, 학습 신호, 방향성 |
| 리스크 관리 | /10 | 경력 안정성, 설명 일관성 |

> 총점 또는 평균을 계산하지 않는다.

---

## 섹션 3. 핵심 강점 분석

다음 관점으로 분석한다:

- 실제로 강하게 읽히는 요소 (근거 포함)
- 인터뷰 질문으로 확장될 가능성이 있는 경험
- 신뢰를 만드는 경험 (구체성, 운영, 복잡도)
- 시장에서 차별화되는 이유

---

## 섹션 4. 핵심 리스크 분석

다음 관점으로 분석한다:

- 실제 감점 가능성이 있는 요소 (근거 포함)
- veto risk 가능성 여부
- 설명 부족 영역
- interview verification 필요 영역

**리스크만 나열하지 않는다. 함께 설명할 것:**
- 유지해야 할 강점
- 보완 우선순위 (1~3순위)

---

## 섹션 5. 환경별 Trade-off 해석

아래 조직 유형 기준으로 강점/리스크가 달라지는 이유를 설명한다:

| 환경 | 강점 또는 리스크 | 이유 |
|---|---|---|
| 스타트업 | | |
| 플랫폼 조직 | | |
| 대기업 | | |
| AI 조직 | | |
| 글로벌 조직 | | |

> 모든 환경을 억지로 채울 필요는 없다. 유의미한 차이가 있는 환경만 포함한다.

---

## 섹션 6. Multi-Evaluator Consensus

각 관점에서의 해석을 요약한다:

**ATS 관점**
- 파싱 안정성, keyword alignment 수준

**리크루터 관점**
- 인터뷰 호출 의향, 첫인상, 경력 흐름 신호

**실무자 관점**
- 기술 신뢰도, 운영 현실감, 함께 일하고 싶은 신호

**임원 관점**
- 조직 기여 가능성, 성장 궤적, 리스크 수용 여부

**Consensus 결론:**
- 어느 그룹이 강하게 긍정하는가
- 어느 그룹이 주요 우려를 제기하는가
- 실제 veto 가능성이 어디에 있는가

---

## 섹션 7. 최종 인터뷰 가능성 해석

**판정 (아래 중 하나):**

| 판정 | 기준 |
|---|---|
| **Strong Hire** | 명확한 경쟁력, 강한 인터뷰 유도력, 낮은 리스크 |
| **Hire** | 인터뷰 적합, 일부 확인 필요하지만 긍정적 |
| **Lean Hire** | 긍정 요소 있으나 불확실성 존재, 추가 검증 권장 |
| **Lean No Hire** | 리스크가 강점보다 우세, 특정 조건 충족 시 재검토 가능 |
| **No Hire** | 명확한 JD mismatch 또는 veto risk 존재 |

**함께 설명할 것:**
- 왜 그렇게 판단했는지 (핵심 evidence 연결)
- 어떤 조건이면 평가가 달라질 수 있는지
- confidence 수준 (높음 / 중간 / 낮음)

---

## Decision Traceability

최종 판단은 핵심 evidence와 연결 가능해야 한다:

- 어떤 경험이 긍정 판단에 가장 영향이 컸는지
- 어떤 리스크가 핵심 감점이었는지

추적 가능하게 설명한다.
