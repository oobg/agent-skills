# Dark SaaS Design

검정 배경에 포인트 하나를 쓰는 한국어 B2B SaaS 시각 언어로 화면을 구현하는
에이전트 스킬입니다. 색과 간격, 글자 위계, 움직임을 계산으로 고정해 설명 없이
같은 톤을 재현합니다.

## 언제 사용하나요?

- 다크 랜딩과 마케팅 페이지를 만들거나 고칠 때
- 제품 소개, 기능 상세, 요금 페이지를 같은 언어로 이어 붙일 때
- 같은 언어로 라이트 제품 화면까지 이어 붙일 때
- `/dark-saas-design` 으로 명시 호출할 때

Day0 신호가 있는 작업(`day0-design`), 문구만 다듬는 작업(`ux-writing`), 진단만
하는 작업(`design-slop-audit`), 라이트 대시보드만 만드는 작업에는 쓰지 않습니다.

브랜드 색이 이미 정해져 있어도 쓸 수 있습니다. 그 색의 명도를 재서 대비 창
안이면 그대로 쓰고, 밖이면 로고와 강조 글자에 두고 면으로 깔리는 자리에는 같은
색상에서 창 안으로 끌어온 값을 씁니다.

## 값은 계산에서 나옵니다

외운 값이 없습니다. 네 축에서 파생합니다.

| 축 | 규칙 |
| --- | --- |
| 색 | OKLCH 좌표 + WCAG 대비 하한 |
| 간격 | 8pt 사다리 (8·16·24·32·48·64·96·128) |
| 형태 | radius = 컨테이너 높이 × 0.125, 짝수 반올림, 상한 12px |
| 활자 | 크기는 4의 배수, 행간은 8의 배수 |

포인트 색이 명도 창 하나로 결정되는 것이 이 시스템의 출발점입니다. CTA 면 위
흰 글씨가 읽히려면(4.5:1) 어두워야 하고, 검정 배경에서 면이 도드라지려면(3:1)
밝아야 합니다. 둘을 함께 만족하는 구간은 OKLCH 명도 0.50~0.58 하나뿐이고,
이 창의 위치는 색상을 어디에 두든 거의 움직이지 않습니다.

## 핵심 요약

- **포인트:** 하나. 기본값 `#863ad2` (흰 글씨 5.92:1, 검정 면 3.55:1)
- **면:** 검정 위 검정 + `#2b2b2b` 1px 보더. 그림자 0, 글래스 0
- **폰트:** Pretendard Variable 한 벌, 굵기는 `font-variation-settings: "wght"`
- **격자:** 컨테이너 1200px, 세로 리듬 128px(모바일 64px), gap 48px
- **형태:** radius 12 / 8 / 6 세 값
- **모션:** 등장, 스택, 리빌, 마퀴, 글로우, 전환 여섯 가지, 이징 하나

## 교체할 수 있는 것과 없는 것

| 교체 가능 | 고정 |
| --- | --- |
| 포인트 색상 | 포인트가 하나라는 것 |
| 컨테이너 폭 | 12칼럼 정수 분할이 떨어질 것 |
| 서체 | 한 벌일 것, 굵기를 가변축으로 줄 것 |
| 기준 글자 크기 | 크기가 4의 배수, 행간이 8의 배수일 것 |

왼쪽을 바꿀 때는 `references/derive.md`의 계산을 다시 돌려 `tokens.css`를 새로
만듭니다. 값 하나만 손으로 고치면 그 값만 시스템 밖으로 떨어집니다.

특정 사이트의 룩얼라이크를 만드는 용도로는 쓰지 않습니다. 로고, 상호, 카피,
미디어 에셋은 포함하지 않으며 재현 대상도 아닙니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `SKILL.md` | 라우팅, 아이덴티티, 구현 규칙, 금지 목록, 자가 점검 |
| `references/tokens.css` | 색, 타이포, 간격, radius, 모션 토큰 (`--ds-*`) |
| `references/derive.md` | 값의 파생 규칙과 교체 절차, 교체 체크리스트 |
| `references/pages.md` | 증명 축, 면 리듬, 페이지 아키타입 5종, 블록 카탈로그 |
| `references/patterns.md` | 타입 스케일 표, 다크와 라이트 컴포넌트 레시피, 비주얼 에셋, 제품 UI |
| `references/motion.md` | 등장, 스택, 리빌, 마퀴, 글로우, 전환과 접근성 대응 |
| `references/ontology-boost.md` | 온톨로지가 있을 때만 여는 선택 모듈 |
