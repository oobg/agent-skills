# Dark SaaS Design

검정 배경에 바이올렛 포인트 하나를 쓰는 한국어 B2B SaaS 시각 언어로 화면을
구현하는 에이전트 스킬입니다. 색과 간격, 글자 위계, 움직임을 고정해 설명 없이
같은 톤을 재현합니다.

## 언제 사용하나요?

- 다크 랜딩·마케팅 페이지를 만들거나 고칠 때
- 제품 소개, 기능 상세, 가격 페이지를 같은 언어로 이어 붙일 때
- 같은 언어로 라이트 제품 화면까지 이어 붙일 때
- `/dark-saas-design` 으로 명시 호출할 때

브랜드 색이 이미 정해진 작업, Day0 신호가 있는 작업(`day0-design`), 문구만
다듬는 작업(`ux-writing`), 진단만 하는 작업(`design-slop-audit`)에는 쓰지
않습니다.

## 핵심 요약

- **포인트:** `#622eec` 하나 (라임 `#c9fd21`은 배지 한두 개까지)
- **면:** 검정 위 검정 + `#333` 1px 보더. 그림자 0, 글래스 0
- **폰트:** Pretendard Variable 한 벌, 굵기는 `font-variation-settings: "wght"`
- **격자:** 컨테이너 1224px, 세로 리듬 120px(모바일 60px), gap 64px
- **형태:** radius 10 / 12 / 8 세 값
- **모션:** 등장·스티키 스택·스크롤 리빌·마퀴·글로우 다섯 가지, 이징 하나

## 출처

운영 중인 한국어 B2B SaaS 랜딩 한 곳을 2026-09-04에 실측했습니다. 페이지가
내보낸 CSS 변수 정의를 그대로 회수하고, Chromium 1440px·390px 렌더링에서
`getComputedStyle` 값을 뽑고, 제품 목업은 PNG 픽셀을 샘플링했습니다.
`tokens.css`에 값마다 `[정본]`과 `[샘플]`을 표시해 두었습니다.

가져온 것은 색·간격·위계·모션 규칙뿐입니다. 로고, 상호, 카피, 미디어 에셋,
섹션 구성 문구는 포함하지 않으며 재현 대상도 아닙니다. 특정 사이트의
룩얼라이크를 만드는 용도로는 쓰지 않습니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `SKILL.md` | 라우팅, 아이덴티티, 구현 규칙, 금지 목록, 자가 점검 |
| `references/tokens.css` | 색·타이포·간격·radius·모션 토큰 (`--ds-*`) |

| `references/motion.md` | 등장·스티키·리빌·마퀴·글로우와 접근성 대응 |
