# 페이지 아키타입과 섹션 조립

랜딩 한 장으로 끝나는 제품은 없다. 이 문서는 **어떤 페이지에 어떤 블록을 몇 개
쌓을지**를 정한다. 개별 블록의 규격은 `patterns.md`에 있다.

## 순서는 고정이 아니다

실측한 다섯 페이지의 섹션 구성이 전부 다르다.

| | 랜딩(홈) | 제품 허브 | 기능 상세 | 가격 | 뉴스룸 |
| --- | --- | --- | --- | --- | --- |
| 전체 높이 | 7965 | 6977 | 5735 | 5532 | 3051 |
| 본문 면 | 전부 다크 | 라이트 | 라이트 | 라이트 | 라이트 |
| 히어로 | 865px 좌측 | 600px 좌측 | 600px 좌측 | 640px **가운데** | **359px** |
| 본문 블록 수 | 6 | 6 | 4 | 5 | **1** |
| 반복 블록 | 스택 카드 ×3 | 기능 그룹 ×3 | 기능 그룹 ×3 | — | 목록 행 ×13 |
| CTA 배너 | 있음 | 있음 | 있음 | 있음 | **없음** |

**같은 순서를 복제하지 않는다.** 제품이 무엇을 파느냐에 따라 블록을 고르고
개수를 정한다. 고정된 것은 세 가지뿐이다.

1. 다크 히어로로 연다.
2. 보라 CTA 배너 + 다크 푸터로 닫는다.
3. 그 사이에서 면 색을 교차시킨다.

## 면 리듬이 페이지 성격을 만든다

이 디자인에서 섹션을 나누는 것은 보더가 아니라 **면 색**이다.

- **랜딩(홈)**: 처음부터 끝까지 검정. 카드 보더와 여백만으로 구분한다.
  브랜드를 각인시키는 자리라 톤을 흐트러뜨리지 않는다.
- **제품·가격 페이지**: 히어로만 검정 → 본문 라이트 → 강조 한 번 검정 반전 →
  푸터 검정. 읽어야 할 정보가 많은 페이지라 라이트로 간다.

라이트 본문 안에서는 세 면을 번갈아 쓴다.

| 면 | 토큰 | 쓰는 자리 |
| --- | --- | --- |
| 흰색 | `--ds-light-bg` | 기능 그룹, 요금제, 후기 — 정보를 읽는 자리 |
| 회색 밴드 | `--ds-light-band` | 스테이트먼트 — 숨을 고르는 자리 |
| 보라 틴트 | `--ds-light-tint` | 전환 유도 — 결정을 요구하는 자리 |
| 검정 반전 | `--ds-bg` | 보안·신뢰 — 무게를 주는 자리 |

**같은 면을 세 블록 넘게 연속하지 않는다.** 기능 그룹을 셋 이어 붙였다면
다음은 밴드나 반전으로 끊는다.

## 아키타입 1 — 랜딩 (홈)

브랜드 첫인상. 전부 다크. `patterns.md` §6 스택 카드가 주력이다.

```text
다크 히어로 (좌측, 210px 여백)
  ↓ 120px
리빌 문장 + 대형 비주얼   ← 한 쌍. 문장 아래 64px에 목업이 붙는다
스택 카드 ×3              ← 제품의 핵심 주장 3개
로고/데이터 출처 스트립
신뢰 2-up
FAQ
CTA 배너 + 푸터
```

**리빌 문장을 단독 블록으로 두지 않는다.** 실측 원본은 문장 아래 64px에
1224×1000 제품 비주얼이 붙어 있고, 히어로에서 문장, 비주얼까지가 한 흐름으로
읽힌다. 문장만 빈 화면에 띄우면 페이지가 그 자리에서 끊긴다. 자세한 진행률
매핑은 `motion.md` §3.

## 아키타입 2 — 제품 허브

제품군 하나를 통째로 소개한다. 기능을 **동사 그룹**으로 묶는 것이 핵심이다.

```text
다크 히어로 (좌측 + 제품 목업 우측, 600px)
스테이트먼트 밴드      ← 다크→라이트 이음매
기능 그룹 ×3           ← 연결합니다 / 정리합니다 / 분석합니다
다크 반전 (보안·신뢰)
틴트 밴드 (가격 유도)
후기 3-up
CTA 배너 + 푸터
```

동사 그룹은 제품의 **작업 순서**를 따른다. 사용자가 처음 하는 일이 첫 그룹이다.
기능을 중요도순으로 늘어놓지 않는다.

## 아키타입 3 — 기능 상세

기능 하나를 깊게 판다. 허브보다 짧고, 문제 제기로 시작한다.

```text
다크 히어로 (좌측 + 해당 기능 목업, 600px)
문제 제기 밴드         ← 질문형 2줄. "…하고 계신가요?"
기능 그룹 ×2~3         ← 항목 수는 1~3개로 유동
CTA 배너 + 푸터
```

허브의 스테이트먼트 밴드가 여기서는 **질문**이 된다. 선언이 아니라 질문으로
열어야 이 기능이 왜 필요한지가 선다. 후기와 보안은 허브에 두고 여기선 뺀다.
같은 내용을 하위 페이지마다 반복하면 페이지가 무거워진다.

## 아키타입 4 — 가격

유일하게 **히어로를 가운데 정렬**한다. 비교가 목적이라 좌우 균형이 필요하다.

```text
다크 히어로 (가운데, 640px)
요금제 카드 3-up
스테이트먼트 밴드
설명 섹션 ×2           ← 왜 이 가격인가 / 어디서 수익을 내는가
FAQ (라이트)
CTA 배너 + 푸터
```

가격이 무료거나 단순하면 **왜 그런지를 설명하는 섹션이 요금제 카드보다 길어도
된다.** 실측 페이지가 그렇다. 숫자보다 신뢰가 결정을 만든다.

**가격은 앵커가 아니라 페이지다.** 제품 허브의 틴트 밴드는 가격으로 보내는 유도
장치이지 가격 그 자체가 아니다. 내비의 `가격`을 제품 페이지 안의 앵커로 걸면
사용자가 CTA 밴드에 도착해 "가격이 어디 있지?"가 된다. 실제로 겪은 실수다.

## 아키타입 5 — 목록 (뉴스룸·자료실)

가장 짧고 단순하다. 히어로에 목업도 글로우도 없다.

```text
짧은 다크 히어로 (359px)   ← 제목 + 한 줄 설명뿐
라이트 목록                 ← 행 + 1px 디바이더. 카드 금지
푸터
```

CTA 배너도 두지 않는다. 소식을 읽으러 온 사람에게 전환을 요구하지 않는다.
실측 원본이 그렇다. 전체 높이 3051px로 전 페이지 중 가장 짧다.

## 블록 카탈로그

조립 단위다. 규격은 `patterns.md`의 해당 절을 본다.

| 블록 | 면 | 규격 | 쓰는 자리 |
| --- | --- | --- | --- |
| 다크 히어로 | 검정 | 좌측 600 / 가운데 640 / 홈 865 | 모든 페이지. 필수 |
| 리빌 문장 + 비주얼 | 검정 | 문장 아래 64px에 목업 | 랜딩만. 한 쌍으로 쓴다 |
| 스택 카드 | 검정 | 1224×468 ×3~4 | 랜딩 주력 |
| 스테이트먼트 밴드 | `#f5f5f5` | 36/700 2줄 가운데 | 페이지당 1개 |
| 문제 제기 밴드 | `#f5f5f5` | 질문형 2줄 | 기능 상세 |
| 기능 그룹 | 흰색 | 헤딩 36/700 + 582 2열 | 허브·기능 상세 주력 |
| 요금제 3-up | 흰색 | 392×550 | 가격 |
| 후기 3-up | 흰색 | 392 패널 카드 | 허브 |
| 다크 반전 | 검정 | 600×252 카드 2-up | 보안·신뢰. 페이지당 1개 |
| 틴트 밴드 | `#f6f5ff` | 가운데 + 버튼 1개 | 전환 유도 |
| FAQ | 검정 또는 흰색 | 438 + 704 2단 | 랜딩·가격 |
| 로고/출처 스트립 | `#ffffff0d` | 풀블리드 마퀴 | 랜딩 |
| CTA 배너 | 보라 | 1224×168 | 모든 페이지. 목록 페이지는 예외 |
| 짧은 히어로 | 검정 | 359px, 목업·글로우 없음 | 목록 페이지 |
| 목록 행 | 흰색 | 행 + 1px 디바이더 | 뉴스룸·자료실 |

## 조립 규칙

1. **필수 셋**: 다크 히어로 / 본문 블록 2개 이상 / CTA 배너.
   목록 페이지만 예외로 본문 블록 1개, CTA 배너 없음.
2. **같은 블록을 연속 반복하지 않는다.** 기능 그룹만 예외로 2~3개 이어 붙인다.
3. **밴드는 페이지당 하나.** 스테이트먼트와 문제 제기 중 하나만 고른다.
4. **본문 블록 6개를 넘기지 않는다.** 넘으면 하위 페이지로 쪼갠다.
5. 하위 페이지가 있으면 후기·보안·가격은 **상위 페이지에만** 둔다.

## 제품 성격에 맞춰 고르기

블록 선택은 취향이 아니라 제품이 무엇을 증명해야 하느냐로 정한다.

| 제품이 파는 것 | 증명해야 할 것 | 주력 블록 |
| --- | --- | --- |
| 데이터·분석 | 숫자가 맞다 | 스택 카드, 기능 그룹, 다크 반전(근거·한계) |
| 자동화·도구 | 손이 덜 간다 | 기능 그룹(동사 헤딩), 문제 제기 밴드 |
| 전문가·중개 | 믿을 만하다 | 후기 3-up, 다크 반전(자격·인증), 틴트 밴드 |
| 금융·자금 | 안전하다 | 다크 반전(보안), 요금제·수수료 설명 섹션 |

무엇을 증명할지 정하지 않은 채 블록부터 고르면, 어느 제품에 붙여도 되는
템플릿이 나온다. 그 상태가 이 디자인에서 가장 나쁜 결과다.
