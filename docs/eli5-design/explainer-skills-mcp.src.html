에이전트 확장

에이전트 스킬과 MCP는 에이전트에 서로 다른 것을 더해요

요청 하나를 끝까지 따라가요. “지난주 주문으로 주간 보고서 만들어 줘”라는 요청에서 스킬과 MCP가 각각 무엇을 맡는지 보여 드려요. 예시 이름은 모두 지어낸 것이에요.

스킬과 MCP를 물건에 빗대면 안내서와 단자예요

둘은 에이전트에 붙는 자리가 달라요

스킬은 필요한 만큼만 나눠서 읽혀요

MCP 클라이언트는 도구 목록을 먼저 묻고 그다음 불러요

그림의 도구
이 서버의 도구는 query_orders예요. 메시지는 모두 JSON-RPC 2.0 형식이에요.
목록부터 묻는 이유
서버마다 도구가 다르고, 쓰는 도중에 바뀔 수도 있어서예요. Claude Code는 시작할 때 도구 이름과 서버 안내만 대화 맥락에 올리고, 도구의 전체 입력 형식은 그 도구가 필요할 때 불러와요.
Claude Code에서 잇기
claude mcp add로 등록하고, 원격 서버는 HTTP로 잇기를 권해요.

주소와 <서버 패키지>는 연결할 서버의 것으로 바꿔요.

보고서 요청 하나가 스킬과 MCP를 번갈아 거쳐요

둘은 더하는 때와 조심할 점이 달라요
